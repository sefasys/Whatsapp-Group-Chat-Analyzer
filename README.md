# WhatsApp Chat Analyzer
An analytical research platform designed to capture quantitative and deep socio-psychological traits inside group messaging dumps.
NOTE: Project is still on progress. 

The purpose of this project is only for reasearching and improving the relationships between co-workers.

In the later circumstances, I intend to make the system identify mobbing, disrespect in the group chat between co-working.

But for now, it only interprets people in the group chat by their psychology.

Group chats can be very flexible and texts can be very misleading. Also, there is a big chance that LLMs can be very problematic, hallucinated. So, it is not fully trustable.

It is created only for research purposes.
